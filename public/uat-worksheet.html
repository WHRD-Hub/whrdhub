How to Use This Worksheet

For each test case: execute the steps, observe the outcome, then mark the Result column as one of:

PASS   FAIL   BLOCKED   N/A   PENDING

Use the Comments column to note bugs, UI issues, copy errors, or improvement ideas. Where a bug is found, note the URL, the action taken, and the actual vs expected outcome. Screenshots are encouraged — paste the filename in the comments cell.
